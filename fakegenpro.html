Frequently asked questions

Where does the profile data come from?

Profiles are fetched from the free RandomUser.me API (no key needed). If it does not respond within 4 seconds, FakeGenPro generates profiles locally so the tool always works.

Is any of the data real?

No. Names, emails, phone numbers and addresses are fictional and intended only for testing and design mock-ups.

Can I use the JSON in my project?

Yes. Press Copy as JSON and paste it into your app, database seed file or API mock.

How many lorem ipsum paragraphs can I create?

Between 1 and 50 paragraphs, sentences or words per click.
